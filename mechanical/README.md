# Diseño Mecánico

Esta carpeta contiene el desarrollo del sistema mecánico del robot G7ACKER, organizado por versiones de diseño CAD.
Cada versión representa una iteración del sistema, permitiendo la evolución y mejora progresiva de los componentes mecánicos.

---

## Estructura

```text
mechanical/
│── V1/
│── V2/
│── V3/
```

Cada carpeta de versión incluye los subsistemas mecánicos del robot, organizados en componentes como:

* Base estructural
* Sistema de dirección
* Soportes de sensores y actuadores
* Elementos de tracción
* Etc.

---

## Contenido por versión

Dentro de cada versión (`V1`, `V2`, `V3`) se encuentran:

* Archivos de diseño en Fusion 360
* Archivos STL para fabricación

Cada subsistema está separado en carpetas independientes para facilitar su modificación, reutilización y fabricación.

---

## Propósito

* Documentar la evolución del diseño mecánico
* Facilitar la fabricación de piezas
* Permitir modificaciones modulares del sistema
* Servir como base para futuras mejoras

---

## Notas

* Mantener nombres de archivos consistentes
* Separar correctamente cada subsistema
* Evitar duplicidad de archivos entre versiones
