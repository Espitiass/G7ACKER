# 🔧 Mechanical

Esta carpeta contiene todo el desarrollo mecánico del robot móvil **G7ACKER**, incluyendo diseños CAD, prototipos, soportes estructurales y versiones finales utilizadas durante la construcción del sistema robótico.

El objetivo principal de este módulo es diseñar y fabricar la estructura física del robot, garantizando:

- Resistencia mecánica
- Estabilidad estructural
- Integración electrónica
- Soporte de sensores
- Sistema de dirección
- Sistema de tracción
- Modularidad del diseño

Todos los componentes fueron desarrollados considerando la integración entre:

- Raspberry Pi 5
- ESP32
- Sensores
- Sistema de locomoción
- Cámaras
- Actuadores

# 🧪 Diseños_de_prueba

Esta sección contiene las primeras iteraciones y prototipos mecánicos desarrollados durante la etapa de diseño del robot.

Aquí se realizaron pruebas relacionadas con:

- Dimensiones del chasis
- Sistemas de dirección
- Ubicación de sensores
- Integración de cámara
- Soportes estructurales
- Distribución de componentes

Los modelos incluidos permitieron validar conceptos antes de fabricar las versiones finales.

## 📁 Contenido

### `bases`
Diseños iniciales del chasis y estructura principal del robot.

### `Camara`
Primeros soportes y adaptaciones para el montaje de la cámara del sistema de visión.

### `direccion_v1`
Primera versión del sistema de dirección mecánica.

### `direccion_v2`
Segunda iteración del mecanismo de dirección con mejoras estructurales y de movilidad.

### `traccion_v1`
Primer prototipo del sistema de tracción y montaje de motores.

# ✅ Diseños_finales

Esta sección contiene las piezas y modelos mecánicos definitivos utilizados en la construcción final del robot G7ACKER.

Los diseños finales fueron optimizados para:

- Mejor estabilidad
- Integración electrónica
- Facilidad de ensamblaje
- Reducción de vibraciones
- Organización del cableado
- Soporte robusto de sensores

## 📁 Contenido

### `Bases`
Estructura principal final del robot, utilizada para soportar todos los módulos mecánicos y electrónicos.

### `direccion_v3`
Versión final del sistema de dirección implementado en el robot.

Incluye mejoras en:

- Precisión de giro
- Resistencia mecánica
- Integración con servomotor
- Estabilidad de movimiento

### `Soporte_camara`
Soporte definitivo para la cámara principal utilizada por el sistema de visión artificial.

### `soporte_infrarrojo`
Estructura diseñada para fijar y posicionar el sensor infrarrojo del robot.

### `soporte_lipo_v1`
Soporte mecánico para la batería LiPo utilizada como fuente de alimentación del sistema.

### `soporte_ultrasonico`
Montaje diseñado para el sensor ultrasónico encargado de la detección de obstáculos.

### `Tracción`
Sistema final de montaje de motores, ruedas y transmisión del robot móvil.

# ⚙️ Diseño mecánico del robot

El diseño mecánico del robot fue desarrollado utilizando herramientas CAD y técnicas de fabricación digital.

El sistema fue diseñado considerando:

- Distribución de peso
- Centro de gravedad
- Espacio para electrónica
- Accesibilidad de mantenimiento
- Modularidad
- Expansión futura

La estructura permite integrar de manera eficiente todos los módulos electrónicos y sensores del sistema autónomo.

---

# 🛠️ Fabricación

Las piezas fueron diseñadas principalmente para fabricación mediante impresión 3D, utilizando materiales termoplásticos compatibles con tecnologías FDM.

Esto permitió:

- Fabricación rápida de prototipos
- Iteración constante de diseños
- Reducción de costos
- Personalización de componentes

---

# 🚗 Función dentro del proyecto

El módulo mecánico constituye la base física del robot móvil G7ACKER.

Su función principal es proporcionar:

- Soporte estructural
- Integración de sensores
- Sistema de locomoción
- Protección de componentes electrónicos
- Plataforma de navegación autónoma

La integración entre diseño mecánico, electrónica y software permitió construir un sistema robótico funcional, modular y escalable.
