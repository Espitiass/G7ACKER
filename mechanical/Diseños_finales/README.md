# 📁 Diseños_finales

La carpeta `Diseños_finales` contiene las versiones finales y optimizadas de los componentes mecánicos utilizados en el robot móvil **G7ACKER**.

Estos diseños corresponden a las iteraciones definitivas desarrolladas después de las etapas de prueba y validación mecánica realizadas durante el prototipado inicial del robot.

En esta sección se consolidan los modelos utilizados para:

- Chasis estructural
- Sistema de dirección Ackerman
- Sistema de tracción
- Soportes electrónicos
- Integración de sensores
- Sistema de cámara
- Distribución mecánica final

Todos los modelos fueron desarrollados para fabricación mediante impresión 3D y ensamblaje modular.

---

# 📂 Estructura de archivos

Dentro de cada subcarpeta se incluyen principalmente los siguientes tipos de archivos:

| Extensión | Descripción |
|---|---|
| `.f3d` | Archivo editable de Autodesk Fusion 360 |
| `.stl` | Modelo 3D listo para impresión |
| `.pdf` | Documento técnico o plano de referencia |

Los archivos `.f3d` permiten modificar los diseños mecánicos, mientras que los `.stl` corresponden a versiones preparadas para fabricación mediante impresión 3D.

# 🛠️ Fabricación de componentes

Todos los modelos STL incluidos en esta carpeta fueron diseñados para fabricación mediante impresión 3D utilizando tecnología FDM.

Esto permitió:

- Fabricación rápida de componentes
- Ajustes iterativos
- Validación física de piezas
- Reducción de costos
- Desarrollo modular del robot

---

# ⚙️ Flujo de desarrollo mecánico

El proceso de diseño utilizado para el desarrollo de los componentes finales siguió una metodología iterativa basada en:

1. Diseño CAD en Fusion 360.
2. Simulación y validación estructural.
3. Exportación de archivos STL.
4. Impresión 3D de prototipos.
5. Ensamble mecánico.
6. Integración electrónica.
7. Pruebas funcionales.
8. Optimización final.

---

# 🚀 Importancia dentro del proyecto

Los diseños finales representan la consolidación del sistema mecánico desarrollado para el robot móvil autónomo G7ACKER.

Gracias a esta etapa fue posible:

- Obtener un sistema mecánico estable
- Mejorar la precisión de dirección
- Optimizar la integración electrónica
- Reducir vibraciones estructurales
- Mejorar la distribución de peso
- Facilitar el ensamblaje modular
- Garantizar compatibilidad con sensores y actuadores

Esta carpeta contiene los modelos definitivos utilizados en la construcción física del robot.
