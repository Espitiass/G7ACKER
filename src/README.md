# Carpeta de Código Fuente 

En esta carpeta se encuentra el **código fuente del robot móvil autónomo G7ACKER**, desarrollado para implementar las funcionalidades principales de control, percepción y pruebas del sistema.

Aquí se almacenan los diferentes **scripts en Python** utilizados durante el desarrollo del proyecto, incluyendo módulos de control de hardware, pruebas individuales de componentes y programas principales de ejecución del robot.

El objetivo de esta carpeta es **centralizar todo el software del sistema**, permitiendo organizar, modificar y escalar el desarrollo del robot de manera estructurada.

---

## Contenido de la carpeta 

Dentro de esta carpeta se incluyen diferentes archivos de código relacionados con el desarrollo del robot. Estos pueden corresponder a módulos de control, pruebas de funcionamiento, integración de sensores, procesamiento de datos o cualquier otra funcionalidad necesaria para el correcto funcionamiento del sistema.

A medida que el proyecto avance, esta carpeta podrá incorporar nuevos scripts y módulos que permitan ampliar las capacidades del robot o mejorar su desempeño.

---

## Organización del código 

El código del proyecto se desarrolla siguiendo un enfoque **modular**, donde cada archivo cumple una función específica dentro del sistema. Esto permite que las diferentes partes del robot puedan desarrollarse, probarse y modificarse de forma independiente sin afectar el resto del sistema.

Esta organización facilita:

- La comprensión del funcionamiento del robot.
- La depuración y mejora del código.
- La integración de nuevas funcionalidades.
- El trabajo colaborativo dentro del equipo.

---

Dado que el proyecto se encuentra en constante evolución, es posible que en esta carpeta se agreguen nuevos archivos relacionados con:
